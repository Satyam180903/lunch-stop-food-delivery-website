# Lunch-Stop Food Delivery Website

A responsive food delivery website that allows users to browse the menu and view details with a clean and simple UI.

## 🔗 Live Demo
https://lunch-stop.netlify.app/

## 🧾 Features
- Responsive layout for desktop and mobile
- Food items section with descriptions and pricing
- Simple and clean design suitable for a food brand

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📂 Project Structure
- `index.html` – main page
- `css/` – stylesheets
- `js/` – JavaScript functionality
- `images/` – assets used in the UI
